# 简化字转换器

**文字改革、二简字转换器。基于自定义字表的汉字简化转换工具。**

**A Chinese script reform and Second-Round Simplified Chinese character converter based on custom conversion tables.**

本项目用于按照自定义 `.wzgg` 字表对汉字文本进行转换，尤其适用于中国大陆二十世纪下半叶文字改革资料、第二次汉字简化方案及其相关方案的整理、试验与文本转换。

## 功能

- 支持单字转换
- 支持词语转换
- 词语按来源词长度最长优先匹配
- 支持同目标规则自动合并
- 支持一繁对多简冲突的交互选择
- 支持连续简化关系自动压缩到最终目标
- 支持连续简化循环检测
- 支持叠字符处理
- 支持 Unicode 补充平面字符
- 支持 Unicode 私用区字符参与叠字符处理
- 字表格式错误时提供行、列及上下文提示
- 仅使用 Python 标准库，无需安装第三方 Python 依赖

## 运行环境

- Python 3
- 支持 Windows、Linux、macOS 等可运行 Python 3 的系统
- 字表及待转换文本应使用 UTF-8 编码

## 目录结构

推荐将程序、字表和待转换文本按如下方式放置：

```text
wzgg_converter.py
code/
    1975A.wzgg
    1975B.wzgg
    1977A.wzgg
    1977B.wzgg
    1977C.wzgg
    1981.wzgg
    1985.wzgg
待转换文件.txt
```

其中：

- `wzgg_converter.py` 为主程序；
- `code/` 目录用于存放转换字表；
- `.wzgg` 为本项目使用的 UTF-8 纯文本字表格式；
- 程序会扫描主程序所在目录中的全部 `.txt` 文件并进行转换。

## 使用方法

在程序所在目录打开终端或命令提示符，运行：

```bash
python wzgg_converter.py
```

如果 `code/` 中只有一个有效字表，程序会直接使用该字表；如果存在多个字表，则会显示选择菜单。

程序完成转换后，会在原 `.txt` 文件所在目录生成：

```text
原文件名（字表名）.wzgg
```

例如：

```text
待转换文件.txt
```

使用 `1977A.wzgg` 转换后会生成：

```text
待转换文件（1977A）.wzgg
```

> [!IMPORTANT]
> 程序会扫描主程序目录中的**全部 `.txt` 文件**。请不要把不希望参与转换的 TXT 文件放在程序目录中。

> [!WARNING]
> 程序在载入字表后会自动进行字表标准化；如果标准化结果发生变化，程序会**直接写回所选 `.wzgg` 字表文件**。建议对重要字表保留备份，或使用 Git 管理其修改历史。

## `.wzgg` 字表格式

`.wzgg` 本质上是 UTF-8 纯文本文件，可以使用普通文本编辑器打开和编辑。

目前支持以下规则：

### 单字转换

```text
A［BC］
A〔BC〕
```

表示将 `B`、`C` 分别转换为 `A`。

### 词语转换

```text
目标词〖来源词〗
```

也可以连续写多个来源词：

```text
目标词〖来源词1〗〖来源词2〗〖来源词3〗
```

这些来源词都会转换为同一目标词。

词语转换先于单字转换执行；当多个来源词可以匹配时，采用**最长优先**。

### 忽略规则

```text
A〈BC〉
```

此类规则会被程序识别并保留，但不参与实际转换。

### 叠字符

在字表中加入：

```text
=叠字符=
```

即可开启叠字符处理。

常规词语和单字转换全部完成后，连续重复且符合条件的字符，从第二个字符起会替换为：

```text
𠚤
```

例如：

```text
哈哈哈哈
```

可处理为：

```text
哈𠚤𠚤𠚤
```

## 字表标准化

程序在转换文本之前会自动检查并标准化所选字表，包括：

1. 合并目标相同的多条单字规则；
2. 对同一来源字对应多个目标字的情况进行冲突提示，并允许用户选择保留哪一个目标；
3. 自动压缩连续简化关系到最终目标；
4. 检测无法确定最终目标的循环关系，并明确报错。

例如：

```text
a［b］
c［a］
```

会被压缩为：

```text
c［ab］
```

如果标准化改变了字表内容，结果会写回原字表文件。

## XSTZQB 配套字体

本项目相关字表及转换结果中可能包含生僻汉字、Unicode 扩展区字符以及私用区（PUA）字符。为了获得较完整、统一的显示效果，推荐使用配套字体 **XSTZQB**。

XSTZQB 是一款为本项目相关文字改革资料和特殊字形显示制作的复合字体，其字形来源目前包括：

- 新宋体（NSimSun）相关字形；
- 天珩字库相关字形；
- 字形维基（GlyphWiki）字形数据；
- 字统网取得的字形资料；
- 作者自行设计、修改和绘制的字形。

XSTZQB 只影响字符的**显示效果**，并不是 `.wzgg` 文件格式或转换程序本身的运行依赖。未安装 XSTZQB 时，程序仍可正常工作，但部分字符可能显示为空框、缺字框或由其他字体代替显示。

## 推荐的 `.wzgg` 编辑方式

`.wzgg` 是 UTF-8 纯文本文件，不需要专用软件。

Windows 用户推荐使用 **Notepad4** 打开和编辑，并将编辑器字体设置为 **XSTZQB**。

其他文本编辑器也可以使用，只要能够：

- 正确读写 UTF-8；
- 使用自定义显示字体；
- 正确处理 Unicode 补充平面字符。

例如 VS Code、Notepad++ 等同样可以用于编辑，但对于仅查看和修改 `.wzgg` 字表而言，Notepad4 较为轻量方便。

## 编码说明

程序按 Unicode 码点处理 Python 字符串，并支持补充平面字符。

字表读取支持 UTF-8 及带 BOM 的 UTF-8；待转换 TXT 文件也应保存为 UTF-8。

为了避免乱码或字符损坏，不建议使用 ANSI、GBK 等编码保存字表或待转换文件。

## 注意事项

- `.wzgg` 文件是文本字表，不是二进制格式；
- 字表中的全角括号属于规则语法的一部分，请勿随意替换为半角括号；
- 字规则中括号外目标必须恰好为一个 Unicode 码点；
- 词语规则可以包含多个字符；
- 程序可能因字表标准化而修改原字表，请注意备份；
- 如果使用了私用区字符，建议配合 XSTZQB 或其他包含相应字形的字体查看；
- 本项目用于文字资料整理、研究及转换；字表所表示的历史方案不等同于现行汉字规范。
